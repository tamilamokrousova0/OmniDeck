# Исходники знака «Триада»

Здесь то, из чего собраны иконки уровнем выше (`icon.icns`, `icon.ico`, png/svg).
Сами иконки лежат готовыми — пересобирать их нужно только при правке знака.

- `build.mjs` — сборка svg/png из описания знака
- `marks.mjs` — геометрия трёх дуг
- `ico.mjs` — упаковка .ico для Windows
- `raster.sh` — растеризация и .icns для macOS
- `canvas.json` — параметры холста
- `omnideck-brand-directions.html` — исследование направлений, из которого вырос знак

Растровые промежутки (`OmniDeck.iconset/`, `png/`) не хранятся: их
восстанавливает `raster.sh`.
